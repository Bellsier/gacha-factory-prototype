# 그래픽 스타일 실험 v2 — 기존(classic)과 새 스타일(v2) 비교

모든 `pc_*` · `phone_*` · `laptop150_*` 이미지는 **같은 빌드, 같은 저장 데이터**를 Chromium(Playwright)에서
`?style=classic` 과 `?style=v2` 로 각각 열어 같은 자리로 걸어가 찍은 실제 게임 화면입니다.
이동은 PC는 실제 키 입력, 모바일은 터치 조이스틱입니다. `*_closeup` 은 같은 스크린샷에서 잘라낸 부분입니다.

| 기기 | 화면 | 기기 픽셀 비율(DPR) | 아트 픽셀 1개 = 기기 픽셀 (classic → v2) |
| --- | --- | --- | --- |
| `pc` | 1280×800, 확대 3배 | 1 | 3 → 3 |
| `phone` | iPhone 13 에뮬레이션, 확대 2배 | 3 | 6 → 6 |
| `laptop150` | 1280×800, Windows 150% 배율 | 1.5 | **4.5 (4·5 섞임) → 5 (균일)** |

| 파일 | 장면 |
| --- | --- |
| `*_1_plaza` | 광장에서 집 쪽 |
| `*_2_door`, `*_2_door_closeup` | 집 문 앞 (집 · 캐릭터 · 돌길 · 잔디) |
| `*_3_walk_closeup` | 걷는 캐릭터 확대 |
| `*_evening_*` | 저녁 밝기(어둠 0.45) — 따뜻한 조명 비교 |

`sprite_preview_*_6x.png` 는 게임 화면이 아니라 스프라이트 함수가 그린 집과 캐릭터를 6배로 나란히 놓은 미리보기입니다.

## 바뀐 것 (v2에서만, 기본값은 classic)
- 집: 같은 크기(84×73)와 비율에 재질을 새로 그림 — 결이 있는 판자, 둥근 기초 돌, 빛과 그늘이 있는 비늘 지붕, 아치형 문, 빛나는 창, 벽돌 굴뚝
- 캐릭터: 같은 16×22 스프라이트에 마무리 처리 — 머리 모서리 둥글게, 따뜻한 짙은 색 안쪽 외곽선(검정 아님), 왼쪽 위 빛·오른쪽 아래 그늘, 머리 윤기, 계단식 픽셀 그림자
- 잔디: 불규칙한 덩어리 색, 1픽셀 풀잎(밝은 끝 · 어두운 뿌리), 작은 풀포기와 꽃
- 돌길: 엇갈린 둥근 조약돌, 돌마다 밝은 윗면과 그늘진 아랫면, 이끼 낀 줄눈, 길 둘레 1픽셀 그림자
- 선명도: 아트 픽셀 하나가 항상 정수 개의 기기 픽셀이 되도록 그리기 배율을 맞춤 (DPR 1.25 · 1.5 · 2.625 등)
