# 집 외관 1차 개선 — 변경 전후 비교

모든 `pc_*` / `phone_*` 이미지는 같은 저장 데이터(마을 배치 layout 3)를 변경 전 빌드(`claude/integration-village-character`)와
변경 후 빌드(`claude/house-exterior-v1`)에 각각 불러와, Chromium(Playwright)에서 같은 자리로 걸어가 찍은 실제 화면입니다.
이동은 PC는 실제 키 입력, 모바일은 터치 조이스틱, 출입은 E 키 / 행동 버튼입니다.

- PC: 1280×800, 확대 3배 / 모바일: iPhone 13 에뮬레이션(390×844), 확대 2배
- `*_before_*` = 변경 전, `*_after_*` = 변경 후

| 파일 | 장면 |
| --- | --- |
| `*_1_plaza_view` | 광장 한가운데서 집 쪽을 본 화면 |
| `*_2_door`, `*_2_door_closeup` | 집 문 앞 (캐릭터와 집 한 화면) |
| `*_3_side_wall` | 집 오른쪽 벽에 붙어 선 자리 (충돌 확인) |
| `*_4_after_exit` | 집에 들어갔다가 문으로 걸어 나온 직후 |

`sprite_preview_*_6x.png` 는 게임 화면이 아니라, 게임의 스프라이트 함수가 그린 집과 캐릭터를 6배로 나란히 놓은 미리보기입니다.
