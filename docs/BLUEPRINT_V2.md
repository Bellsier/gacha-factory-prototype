# 채굴 공방 디자인 청사진 v2

상태: 확정 / 동결

목적: 핵심 게임 구조를 정의하는 상위 설계 문서다. 세부 수치와 미확정 시스템은 별도 설계 문서에서 결정한다.

## 1. 핵심 성장

게임의 장기적인 성장 중심은 **생산라인의 증가와 정리**다.

핵심 루프:

생산라인 증가 → 공장 복잡도 증가 → 병목 발생 → 재배치/정리 → 자동화 → 새 생산라인 해금

플레이어는 단순히 자원을 모으는 것이 아니라, 점점 복잡해지는 공장을 설계하고 개선한다.

## 2. 생산 구조

생산은 다음 구조를 기본으로 한다.

복수 광물 → 1~N단계 가공 → 분기/합류 → 완제품

중간 가공품은 여러 생산라인에서 재사용될 수 있으며, 생산라인은 단순한 일직선 구조에 한정하지 않는다.

## 3. 생산라인 최소 단위

실질적인 생산라인 구성 단위는 **Node + Link**다.

- Node: 생산 또는 물류 기능을 수행하는 지점
- Link: Node 사이의 공간적/논리적 연결

## 4. Node 종류

초기 핵심 Node:

- Production
- Storage
- Splitter
- Merger

세부 Node 종류는 이후 필요성이 확인될 때 추가한다.

## 5. 물류 시뮬레이션 원칙

개별 아이템 실제 이동은 시뮬레이션하지 않는다.

시뮬레이션 대상:

- Node 생산/소비
- Node 사이 연결
- 연결 처리량(throughput)
- 재고량
- 병목

시각적 자원 이동은 애니메이션으로 표현할 수 있지만 게임 로직은 개별 아이템 객체에 의존하지 않는다.

## 6. Storage 원칙

창고는 기본적으로 **독립 재고**다.

서로 다른 창고 재고를 전역 인벤토리처럼 자동 공유하지 않는다.

향후 연구/물류 시스템을 통해 창고 간 연결/물류 네트워크 도입 가능하나 별도 설계에서 결정한다.

## 7. Research

연구는 범용 능력치 증가보다 **새로운 생산 가능성과 시스템 기능의 해금**을 중심으로 한다.

예:

- 새 레시피
- 생산시설
- 물류 기능
- 자동화 기능

구체적인 연구 트리는 별도 설계에서 결정한다.

## 8. Facility Upgrade

시설 업그레이드는 생산라인의 **처리량과 용량**을 높이는 방향으로 설계한다.

성장 공식과 비용은 별도 설계에서 결정한다.

## 9. Automation

자동화는 플레이어의 반복적인 직접 개입을 줄이는 시스템이다.

자동화가 생산량을 무조건 증가시키는 개념은 아니며, 생산라인의 흐름과 운영에 대한 플레이어 개입 감소를 중심으로 한다.

## 10. Worker

Worker는 소수의 명확한 역할을 중심으로 설계한다.

후보 역할:

- 채굴
- 운송·물류
- 기계 운영
- 관리·기술

정확한 역할 수와 능력 구조는 별도 설계에서 결정한다.

## 11. Worker 모집

플레이어에게 보이는 개념은 가챠보다 **채용**이다.

채용공고 → 지원자 등장 → 지원자 검토 → 고용 → 생산라인 배치

현재 프로토타입의 랜덤 모집 메커니즘은 내부 구현으로 재사용할 수 있지만, 장기적으로 RPG식 희귀도 경쟁보다 역할과 특성 중심으로 설계한다.

## 12. 생산라인 분석

플레이어가 공장 상태를 이해할 수 있도록 다음 정보를 제공하는 방향으로 설계한다.

- 생산량
- 소비량
- 재고
- 처리량
- 병목

세부 분석 UI와 시각화는 별도 설계에서 결정한다.

## 13. 장기 성장 원칙

장기 성장의 중심은 **더 많은 생산라인을 만들고 더 복잡한 공장을 효율적으로 정리하는 것**이다.

Prestige, Sector 등의 메타 구조는 아직 확정하지 않는다.

## 14. 확장 후보

향후 별도 설계 대상:

- Blueprint 복사/붙여넣기
- 생산라인 분석/병목 시각화 강화
- Sector 기반 장기 성장
- 물류 네트워크
- 창고 간 연결

위 기능들은 v2의 확정 사항이 아니라 향후 별도 설계에서 결정한다.

## 15. 설계 원칙

1. 생산라인 중심 게임플레이를 우선한다.
2. 공간과 물류가 의미 있는 의사결정을 만들어야 한다.
3. 개별 아이템 이동 시뮬레이션을 하지 않는다.
4. 복잡한 비율과 소수점 계산을 피하고 가능한 한 직관적인 정수 단위를 사용한다.
5. Worker는 생산라인의 주인공이 아니라 보조 시스템이다.
6. 연구, 시설 업그레이드, 자동화의 역할이 서로 겹치지 않게 한다.
7. 미확정 시스템은 문서에 억지로 확정하지 않고 별도 설계에서 결정한다.
