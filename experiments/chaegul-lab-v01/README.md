# 채굴 공방 실험판 v0.1

키보드로 이동하며 광물을 캐고 공방을 성장시키는 독립 Canvas 2D 실험판입니다. 지상 7지역과 B1–B4를 탐험하며 채굴·제작·전투·농사·시설 복구·운송을 경험할 수 있습니다. 지하에는 일반 몬스터가 없습니다.

기존 게임을 완전히 이식한 버전이 아닙니다. 기존 일꾼·가챠·경제 시스템은 포함하지 않으며 기존 저장 호환성이나 기능 동등성을 주장하지 않습니다. 집·공방·창고를 초원에 배치한 것은 플레이 검증용 임시 구성입니다.

## 실행

빌드 없이 이 폴더의 `index.html`을 정적 HTTP 서버로 제공하면 됩니다. 게임 실행에는 외부 이미지·폰트·네트워크 API가 필요하지 않습니다.

```sh
python3 -m http.server 43191
```

브라우저에서 `http://localhost:43191/`을 여세요. 단일 HTML 배포본도 패키징 도구에서 생성합니다. `file://` 실행은 관리형 Chromium 정책 때문에 이전 검증이 차단되었으므로 성공을 보증하지 않습니다. 로컬 HTTP 실행을 권장합니다.

## 조작

| 키 | 행동 |
| --- | --- |
| WASD / 방향키 | 이동 |
| E | 가까운 대상 상호작용·채굴·탑승·하차 |
| Space / F | 근접 공격 / 바라보는 방향으로 원거리 공격 |
| B | 제작한 자전거 탑승·하차, 지상 전용 |
| Q | 순무 1개로 체력 30 회복 |
| G | 제작한 정원 등불 배치, 최대 8개 |
| I / M | 공용 저장소 / 지도·발견 기록 |
| P / Esc | 수동 저장 / 패널 닫기 |

패널이 열리면 세계 시간이 멈춥니다. 수레에서는 A/D로 기존 레일을 따라 이동하고 E로 내립니다. 지도는 위치·기록 안내이며 이동 메뉴는 아닙니다.

## 첫 플레이와 탐험

초원의 구리 8개와 돌 4개를 모아 공방에서 채굴 기술을 연구하고 구리 곡괭이를 만드세요. 고원 등에서 철을 채굴한 뒤 제작 기술과 강철 곡괭이로 수정·불씨석을 채굴할 수 있습니다. 광맥은 네 번 채굴하면 24초 동안 쉬며, 각 타격마다 자원 2개와 채굴 경험치가 들어옵니다. 대화 중에는 이 시간이 흐르지 않습니다.

| 지역 | 주요 행동 |
| --- | --- |
| 푸른 초원 | 집 회복, 공방 제작·연구, 공용 창고, 구리·돌, 주민, 밭, 우물, 지하 입구 |
| 이끼숲 | 목재 채집, 장인 작업대 복구와 기록, 지상 전투 |
| 서리 고원 | 철 채굴, 사원 등불 순서 복구 |
| 안개 늪지 | 수로 수문 복구, 주민 대화, 철 채굴 |
| 별빛 수정 지대 | 수정 채굴, 연구 관측기 복구 |
| 붉은 바위 산맥 | 철 채굴, 무너진 광산 통로 개방 |
| 잿불 화산 지대 | 불씨석 채굴, 지열 시설 복구 |
| B1 | 돌 2개로 기존 철도 분기기 복구, 레일 수레 |
| B2 | 전력 장치: 가운데 → 왼쪽 → 오른쪽 |
| B3 | 난방 장치: 오른쪽 → 가운데 → 왼쪽 |
| B4 | B2·B3 복구 후 마지막 연구실과 기록 복원 |

지상은 표지판으로 초원 ↔ 숲 ↔ 고원 ↔ 늪지 ↔ 수정 지대 ↔ 산맥 ↔ 화산 ↔ 초원으로 이어집니다. 초원 남쪽 표지판에서 B1으로 내려갑니다. 사원 등불 순서는 왼쪽 → 가운데 → 오른쪽입니다. 잘못 누른 장치는 순서 진행이 초기화됩니다.

밭은 E로 심기 → 물주기 → 플레이 시간 30초 후 수확하며 순무 3개를 얻습니다. 체력이 소진되면 재료를 보존한 채 집 앞으로 돌아옵니다. 텔레포터는 고대 기술 연구 후 각 지역에서 직접 활성화한 장치끼리만 이용합니다.

장비는 제작 즉시 적용됩니다. 자전거는 B로 탑승합니다.

## 저장

독립 키 `chaegulGongbang.experimental.v01`, 형식 버전 1을 사용합니다. 기존 `gachaFactorySave` / `gachaFactoryView`는 읽거나 쓰지 않습니다. 약 10초 간격 자동 저장과 P 수동 저장을 제공하며, I 패널에서 실험판 JSON 내보내기·가져오기가 가능합니다.

손상되었거나 지원하지 않는 버전의 저장은 자동으로 덮어쓰지 않고 원본 내보내기를 제공합니다. 저장소 접근·쓰기 실패 시에도 게임은 진행할 수 있으며 JSON으로 진행을 보관할 수 있습니다. 가져오기는 현재 진행을 바꾸므로 확인 문구를 읽으세요. 보호 중인 원본이 있다면 별도 내보내기 후 가져오세요.

## 개발과 검증

```sh
npm test
npm run test:browser
npm run package
```

게임 자체는 빌드가 필요하지 않습니다. 브라우저 테스트에는 Playwright 및 Chromium과 실행 중인 HTTP 서버가 필요합니다. `GAME_URL`로 테스트 주소를 지정할 수 있습니다. `tools/`의 패키징 도구는 분리 소스에서 단일 HTML과 ZIP 배포물을 생성하는 용도입니다.

환경 초기화로 작업 파일이 사라진 후 대화에 남은 소스를 복원했습니다. 현재 복원본의 전체 검증과 패키징은 진행 중이며 이 문서는 최종 통과 결과를 주장하지 않습니다. 최종 실행 결과는 별도 검증 보고서를 확인하세요.

설계 경계는 [docs/DESIGN.md](docs/DESIGN.md), 모듈과 통합 방법은 [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md), 진행 기록은 [docs/PROGRESS.md](docs/PROGRESS.md)에 있습니다.
