# 독립 Canvas 실험판 설계와 경계

사용자는 독립 플레이 실험판을 구현·검증하는 범위를 승인했습니다. 정식 게임의 청사진·원래 배치·저장 형식을 변경하지 않고, 작은 월드에서 채굴과 성장의 감각을 검토할 수 있게 합니다.

## 참고 기준

Task112 관련 문서와 HANDOFF, BLUEPRINT 23/24장, TOPDOWN_TRANSITION, README를 연결 도구로 읽었습니다. 참고 커밋은 PR #34의 `d21fb3437d11b2d78fe552e2760520b3c9cc388b`입니다. 이는 문서 참고 기준이며 해당 원본 코드를 실험판에 통합했다는 뜻이 아닙니다.

전달용 원격 브랜치는 `codex/chaegul-lab-v01-20261017`, 기준 main은 `e00c62d867d8bd6fdc39434f47ac9504d3696eb5`입니다. 실험판은 `experiments/chaegul-lab-v01/`에 격리하는 계획이며 원래 PR #34와 main은 변경하지 않습니다. 전달 상태와 최종 검증은 별도 보고합니다.

## 플레이 범위

1200×900 크기의 11개 맵을 Canvas 2D와 직접 그린 도형으로 표현합니다. 대각선 이동 속도를 정규화하고 축별 충돌·작은 이동 단계로 장애물을 처리합니다. 카메라는 지도 경계 안에서 플레이어를 따릅니다. 이름이 있는 가까운 대상에 E로 상호작용합니다.

지상 7지역은 초원·숲·고원·늪지·수정 지대·산맥·화산입니다. B1–B4에는 일반 몬스터를 두지 않습니다. 지상은 양방향 표지판으로 순환하고, 초원 남쪽에서 B1에 진입해 네 층을 왕복합니다.

핵심 연결은 채굴 → 공용 재고·경험 → 공방 연구·제작 → 자동 장착 → 상위 광석입니다. 구리 곡괭이는 철, 강철 곡괭이는 수정·불씨석을 채굴합니다. 전투는 검과 투사체, 추적·피격·전리품·체력 소진 후 귀환을 제공합니다. 수치와 성장 속도는 임시 밸런스입니다.

초원에서는 집 회복, 주민 대화, 공용 저장소, 농사, 우물 복구, 등불 배치를 제공합니다. 집과 공방을 초원 안에서 도로로 나눈 배치는 임시이며 정식 위치 결정이 아닙니다. 다른 지상 지역은 장인 작업대·사원 등불·수문·관측기·터널·지열 장치와 지역 기록으로 구분합니다.

B1은 새 철도를 놓는 대신 기존 레일을 복구하고 수레를 이용합니다. B2 전력과 B3 난방 장치를 올바른 순서로 복구하면 B4 연구실 기록을 복원할 수 있습니다. 자전거는 지상 전용이며 텔레포터는 직접 활성화한 지점 사이에서만 이동합니다.

## 포함하지 않는 범위

기존 일꾼·가챠·경제 시스템과 원본 UI 전체는 이식하지 않았습니다. 기존 기능 동등성·저장 호환성을 검증하지 않습니다. 이야기 문구는 유적과 탐사의 단편을 다루며 미확정 재앙 연표나 범인을 새로 확정하지 않습니다.

## 저장과 검증 원칙

독립 저장 키와 버전을 사용합니다. 손상·미래 버전 저장은 자동 덮어쓰기를 막고 원본 내보내기를 제공합니다. JSON 가져오기는 실험판 형식만 받습니다. 진행 상태를 저장하며 카메라·입자 같은 화면 효과는 저장하지 않습니다.

단위 규칙 검증과 실제 브라우저 조작 검증을 구분합니다. 정상 플레이 여정은 게임 상태를 주입하지 않고 키·버튼 입력으로 수행하며, 경계 사례 테스트는 초기 상태를 구성해 검사할 수 있습니다. 관리형 Chromium에서 `file://` 접근이 차단된 이력은 성공으로 간주하지 않습니다. 환경 초기화 후 복원한 소스는 다시 검증하며 최종 결과는 별도 보고합니다.
