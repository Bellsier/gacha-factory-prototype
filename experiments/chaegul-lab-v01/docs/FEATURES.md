# 구현·간소화·미구현 목록

## 실제 구현
- 1200×900 지도 11개, 지역별 팔레트·소품·광맥·행동, 출입구를 통한 왕복.
- Canvas 지형·캐릭터·건물·나무·바위·광맥·몬스터. 걷기, 타격 호, 입자, 연기, 환경 입자, 미니맵.
- WASD/방향키, 대각선 보정, 발밑 충돌과 축 분리, 경계 카메라·화면 크기 대응.
- 근접 광맥 채굴, 즉시 공용 재고, 재생, 채굴 경험치와 표시 레벨, 곡괭이 3등급.
- 공방 근접 제작, 네 기술 연구, 재료 검증·차감, 자동 장착, 강화 검.
- 근접·원거리 공격, 지상 적 추적·접촉 피해·처치·전리품·각 공격 종류 경험치, 자원 보존 귀환.
- 별도 집·공방·창고, 주민 대화, 농사(심기/물주기/성장/수확), 순무 회복, 우물 복구, 등불 제작·배치.
- 지상 자전거, B1 기존 철도 복구·선로 제한 수레·안전 하차, 활성화한 텔레포터 사이 이동.
- 지역별 기록 11개, 고원 사원과 B2/B3 순서 퍼즐, 선행 복구를 요구하는 B4 연구실 완료 목표.
- 독립 저장 키, 자동/수동 저장, JSON 내보내기·가져오기, 손상·미래 저장 보호, 저장 실패 표시.

## 실험용 간소화
- 모든 기능은 새 독립 상태 모델에 구현했다. 기존 경제·제작·채굴 엔진에 연결한 기능은 없다.
- 소형 고정 지도와 양방향 표지판 전환이며 연속 청크 월드는 아니다. 마을·집·공방 간 거리와 모든 수치는 임시다.
- 타격마다 채굴 경험을 기록하고 10회당 표시 레벨이 오른다. 광물 접근 등급은 곡괭이로 결정하며 정식 숙련도 효과 공식은 미구현이다.
- 각 지상 탐험 지역의 적은 단순한 추적형이다. 적 체력·위치는 지역 재진입·새로고침 시 초기화된다.
- 순무 한 종류, 무료 씨앗·물, 플레이 시간 성장이다. NPC 일정·호감도·긴 대화 트리는 없다.
- 복구는 소량 재료 또는 순서 퍼즐이다. 터널은 장애물 개방과 아치 표현으로 통과할 수 있으며 기존 게임의 업체 계약·10분 공사 체계를 이식한 것이 아니다.
- 지하 철도 한 노선만 복구한다. 지상 새 레일 설치는 이번 최소 수레 구현 범위에 포함하지 않았다.
- 물길·용암은 환경 표현이다. 수영·냉기·용암 피해는 구현하지 않았다.
- 이야기 기록은 청사진의 확정된 단편만 전달한다. 미확정 연표·범인·봉인 결과를 새로 확정하지 않는다.

## 미구현 / 미검증
- 기존 일꾼·가챠·자동화·판매·납품·회사·명성 시스템 연동, 기존 저장 마이그레이션·호환성·기능 동등성.
- 정식 픽셀 아트·사운드·컨트롤러·터치 조이스틱·접근성 전체 검증.
- 대규모 월드 스트리밍, 절차적 광맥 랜덤화, 장기 밸런스, 오프라인 경제 진행.
- 본편 스토리 전체, 박물관·감정소·계절 힐링 맵 등 정식 콘텐츠.
- 실물 Chromebook 및 일반 사용자 브라우저의 file:// 실행. 관리형 Chromium에서는 정책으로 차단됐다.

이 항목들은 기존 프로젝트에서 삭제한 기능이 아니라, 별도 실험판에 이식하지 않은 기능이다.
