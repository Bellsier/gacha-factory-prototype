# 채굴 공방

작은 광산과 공방을 천천히 키우는 2D 힐링 경영 게임 프로토타입입니다.

광맥 확보 → 채굴 → 공용 저장소 → 제작소 → 판매 → 골드 → 거점 확장.

## 설계 문서

- [`docs/BLUEPRINT_V3.md`](docs/BLUEPRINT_V3.md) — 현재 게임의 최종 디자인 기준선.

## 실행

정적 웹 페이지입니다. 로컬에서:

```bash
python3 -m http.server 43191 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:43191` 을 엽니다.

또는 `index.html` 을 그대로 열어도 됩니다.

## 테스트

```bash
npm install
npm test
```

## 진행

1. **채굴** 탭에서 월드 광맥을 확보한 뒤 캔다. 캔 광석은 공용 저장소로 들어간다.
2. **개발** 탭의 제작소에서 레시피를 고르고 수동/자동 제작한다. 같은 탭의 기존 제작 카드로도 판매할 수 있다.
3. 골드로 거점을 확장하면 새 지역 광맥이 나타난다.
4. 골드 50이 되면 첫 가챠권 1장을 받는다.
5. **인부** 탭에서 가챠권으로 일꾼을 뽑고 채굴장에 배치한다.
6. 일꾼이 있는 회차에서 골드 200부터 명성 1점. 공식은 `⌊√(골드 ÷ 200)⌋`.

진행 상황은 브라우저 `localStorage`에 자동 저장됩니다 (`saveVersion` 1).
