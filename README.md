# 채굴 공방

작은 광산과 공방을 천천히 키우는 2D 힐링 경영 게임 프로토타입입니다.

광맥 확보 → 채굴 → 공용 저장소 → 제작소 → 판매 → 골드 → 거점 확장.

## 설계 문서

- [`docs/BLUEPRINT_V3.md`](docs/BLUEPRINT_V3.md) — 게임의 최종 디자인 기준선. 23장(통합 최종 설계)이 우선하고, 24장은 지금 코드의 구현 기록이다.
- [`docs/TOPDOWN_TRANSITION.md`](docs/TOPDOWN_TRANSITION.md) — 탑다운 화면의 기술 설계와 Task별 구현 기록.
- [`docs/HANDOFF.md`](docs/HANDOFF.md) — 인수인계 문서: 구현·미구현 기능, 파일 구조, 실행·빌드·테스트 방법.

## 실행

정적 웹 페이지입니다. 로컬에서:

```bash
python3 -m http.server 43191 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:43191` 을 엽니다.

또는 `index.html` 을 그대로 열어도 됩니다.

## 테스트

```bash
npm install
npm test
```

`npm test`는 `tests/regression.test.js`가 `tests/chunks/00.js`부터 번호 순으로 불러 한 번에 실행합니다. 청크를 합친 내용이 전체 회귀 스위트입니다.

## 실행 파일 만들기

```bash
node tools/build-dist.js
```

`dist/`에 두 파일이 생깁니다(저장소에는 올리지 않음).

- `chaegul-gongbang-<커밋>.zip`: 압축을 풀고 `index.html`을 엽니다.
- `chaegul-gongbang-<커밋>-single.html`: CSS와 스크립트를 모두 넣은 파일 하나. 휴대폰에 옮겨 바로 열 수 있습니다.

## 탑다운 전환

그래픽은 2D 탑다운 픽셀아트로 전환하는 중입니다(청사진 23.1, 구현 기록 24장, 설계 [`docs/TOPDOWN_TRANSITION.md`](docs/TOPDOWN_TRANSITION.md)). 기본 화면은 탑다운 월드입니다. 지금의 월드(산맥·터널·산 너머가 있는 작은 월드)는 현행 프로토타입이며, 최종 월드(지상 7개 지역 등)는 청사진 23장에 있습니다.

- PC: WASD·방향키로 걷고, 광맥이나 공방 앞에서 **E** 또는 **Space**로 확보·캐기·들어가기. **T**로 앞에 횃불을 놓거나 거둡니다(최대 12개). 아래 독의 버튼으로 채굴/개발/인부/연구/납품/기록 패널을 열고 **Esc**로 닫습니다.
- 휴대폰: 왼쪽 아래 조이스틱으로 걷고, 오른쪽 아래 버튼으로 행동합니다. 그 위의 횃불 버튼으로 횃불을 놓거나 거둡니다.
- 고용한 일꾼은 공방에서 나와 맡은 광맥까지 걸어가 일합니다(보기만 바뀌고 생산량은 같습니다). 산 너머의 나무와 바위는 지나갈 수 없습니다.
- 시작 마을: 공방 주변의 무너진 **감정소**와 **박물관**을 문 앞에서 E(휴대폰은 행동 버튼)로 복구합니다. 광맥을 손으로 캐다 보면 가끔 **미감정 유물**이 나오고, 감정소에서 감정하면 도감에 등록되며, 박물관에 기증하면 전시됩니다. 같은 일을 아래 독의 **마을** 패널에서도 할 수 있습니다.
- 이전 2.5D 화면: 주소 뒤에 `?view=classic` (다시 `?view=topdown`). 이 선택은 게임 저장과 따로 기억됩니다.

## 진행

1. 월드를 걸어 광맥 앞에서 확보하고 캔다(**채굴** 패널의 버튼으로도 된다). 캔 광석은 공용 저장소로 들어간다.
2. **개발** 탭의 제작 카드에서 제품을 만들고 판매한다. **연구** 탭에서 "제작소 건설"을 연구하면 제작소를 지어 레시피를 정해 둘 수 있고, "자동 제작 장치"를 연구하면 자동 제작을 켤 수 있다.
3. 골드와 제작품으로 거점을 확장하면 새 지역 광맥이 나타난다.
   **연구** 탭에서 "터널 굴착"(1,000G)을 연구해 전문 굴착 업체와 계약한 뒤, 같은 탭의 "터널 공사"에서 공사를 의뢰(5,000G + 마법 합금 5개)한다. 공사는 현실 시간 10분이 걸리고 게임을 꺼 둬도 흐르며, 끝나면 산을 가로지르는 터널이 열려 산 너머의 광맥을 찾아 걸어갈 수 있다.
4. 골드 50이 되면 첫 가챠권 1장을 받는다.
5. **인부** 탭에서 가챠권으로 일꾼을 뽑고 채굴장에 배치한다.
6. **연구** 탭에서 "납품 계약"을 연구하면 **납품** 탭에서 회사에 제품을 보낼 수 있다. 회사의 수주를 완수하면 명성을 얻고(최대 36), 명성이 오르면 거래할 수 있는 회사가 늘고 채굴·판매 배율과 효과가 열린다. 환생(전체 초기화)은 없다.

진행 상황은 브라우저 `localStorage`에 자동 저장됩니다 (`saveVersion` 1).
