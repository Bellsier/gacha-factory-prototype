# 채굴 공방

뽑기 × 공장형 프로토타입. 광석을 캐고, 강철을 만들어 팔고, 가챠권으로 일꾼을 뽑아 공방을 굴립니다.

채굴 → 자원 생산 → 제작 시설 → 제작 → 판매.

우르의 게임과 별개 저장소입니다. 이 폴더만 이 게임에 해당합니다.

## 설계 문서

- [`docs/BLUEPRINT_V2.md`](docs/BLUEPRINT_V2.md) — 공장 청사진. 생산라인/Node+Link/자동화/인력 등 게임의 디자인 기준선(baseline). 구현이 이 문서와 충돌하면 코드가 아니라 청사진 쪽 판단을 우선하고, 차이를 별도로 기록한다.

## 실행

정적 HTML 한 장입니다. 로컬에서:

```bash
python3 -m http.server 43191 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:43191` 을 엽니다.

또는 `index.html` 을 그대로 열어도 됩니다.

## 테스트

```bash
npm install
npm test
```

## 진행

1. **채굴** 탭에서 철광석·석탄을 캔다. 광석은 골드가 아니다.
2. **개발** 탭에서 강철을 제작한 뒤 판매한다. 같은 탭의 제작 시설을 올리면 `craftTime > 0` 레시피가 더 빨리 끝난다.
3. 골드 50이 되면 첫 가챠권 1장을 받는다.
4. **인부** 탭에서 가챠권으로 일꾼을 뽑고 채굴장에 배치한다.
5. 일꾼이 있는 회차에서 골드 200부터 명성 1점. 공식은 `⌊√(골드 ÷ 200)⌋`.
6. 초기화하면 자원·제품·일꾼·본사 투자·제작 시설은 사라지고, 명성 배율만 남는다.

진행 상황은 브라우저 `localStorage`에 자동 저장됩니다.
